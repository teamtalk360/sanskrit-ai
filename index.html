How do I get an API key?
  1. Go to platform.openai.com and sign in (you can use the same email as ChatGPT).
  2. Open Settings → Billing and add a payment method or prepaid credit. The API is pay-per-use and separate from a ChatGPT Plus subscription.
  3. Open API keys and click Create new secret key.
  4. Copy the key (it starts with sk-), paste it above, and tap Test connection.

Only messages you send in a chat go to OpenAI (api.openai.com). Your key is never sent anywhere else.
